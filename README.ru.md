# xDrip+ для iOS

[English](README.md)

Приложение для чтения глюкозы с CGM-сенсоров по Bluetooth и передачи данных в Trio. Этот форк расширяет [xDrip4iOS](https://github.com/JohanDegraeve/xdripswift) поддержкой Ottai/Syai, Sibionics GS1 CN и AiDex/LinX/LumiFlex.

Для сборки используй основную ветку **`custom-build`**.

## Что добавлено

| Сенсоры | Возможности |
|---|---|
| **Ottai CN и Global** | Чтение по Bluetooth, вход в аккаунт, подготовка и активация поддерживаемых новых сенсоров из xDrip, запрос увеличенного срока |
| **Syai** | Чтение по Bluetooth и активация через аккаунт производителя |
| **Sibionics GS1 CN** | Прямое чтение по Bluetooth, локальный расчёт глюкозы, восстановление истории и передача данных в Trio |
| **AiDex X, LinX и LumiFlex** | Драйверы Bluetooth с распознаванием сенсора, учётом прогрева и обработкой глюкозы |

Также сохранены исходное время старта и история GS1 при восстановлении связи. Исправлен показ демонстрационных значений вместо текущей глюкозы в виджете.

### Активация и срок Ottai

Для поддерживаемого **нового Ottai CN или Global** в xDrip реализованы подготовка и активация. Аккаунт производителя и интернет по-прежнему нужны. Спящий CN дополнительно требует пробуждения по NFC — из xDrip с подходящей подписью или внешним считывателем.

При первой активации приложение запрашивает **до 30 дней общего срока**. Затем считывает настройку обратно с сенсора и проверяет результат, прежде чем продолжить активацию. Если сенсор явно отклоняет запрос, приложение может выбрать меньший поддерживаемый срок.

Для **уже активного Ottai CN или Global** в карточке есть действие **Request 30 days total**. Оно сохраняет исходный старт и историю, запрашивая общий срок 30 дней. Дополнительные 30 дней и новая сессия при этом не начинаются. Приложение считывает результат и проверяет, что сенсор остаётся активным.

**Подтверждённая настройка не доказывает работу сенсора после прежнего срока.** Первый физический запуск и длительное продление этой реализацией ещё требуют испытаний. Syai использует срок, заданный производителем при активации; управление 30-дневным сроком относится к Ottai CN и Global.

### GS1 и Trio

Глюкоза GS1 CN рассчитывается локально включённой в проект библиотекой. Чтение уже работающего GS1 и передача его глюкозы в Trio проверялись на iPhone. Поддерживается китайский вариант AA55/V115G.

Отдельный экспериментальный режим показывает ограниченную диагностику после обычного 14-дневного периода. Эти значения остаются в карточке устройства и исключены из основного графика, уведомлений и Trio. Сенсор этим режимом не перезапускается.

## Сборка со своей подписью

Сборка проверена на Mac с Apple silicon и Xcode 27. Для сборочного скрипта нужен Python 3. Готовая GS1-библиотека включена для ARM64 iPhone и Simulator на Apple silicon; для обычной сборки приложения Kotlin и пересборка библиотеки не нужны.

```sh
git clone --branch custom-build https://github.com/d3xr/xdrip-plus.git xdrip-plus
cd xdrip-plus
cp xDripConfigOverride.xcconfig.example xDripConfigOverride.xcconfig
```

Укажи свою Apple Developer Team в локальном `xDripConfigOverride.xcconfig`:

```text
XDRIP_DEVELOPMENT_TEAM = YOURTEAMID
```

Открой `xdrip.xcworkspace`, выбери схему `xdrip` и настрой подпись приложения и расширений. Основное приложение использует HealthKit, App Groups и чтение NFC-тегов. Для обмена с твоей установкой Trio нужны совместимые подписи и App Groups.

Можно собрать в Xcode или выполнить:

```sh
export DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer
bash scripts/build-local.sh
```

Скрипт создаёт подписанный `.app` и выводит его расположение. Установка выполняется отдельно. Ключи подписи, provisioning-файлы и локальный override в Git не добавляются.

**Personal Team:** используй [локальный профиль подписи](docs/build-profiles.md#локальный-personal-team). В нём NFC выключен, Bluetooth и управление сроком сохранены. Для NFC из xDrip нужна подпись с разрешением на чтение NFC-тегов.

## Подключение сенсора

1. Открой **Устройства**, добавь нужный тип сенсора и введи его код или данные аккаунта.
2. Подключись к уже активному сенсору для чтения. Для нового Ottai войди в аккаунт нужного региона, при необходимости пробуди сенсор, подключись и выбери **Start / activate sensor**.
3. Открой **Настройки → Обмен OS-AID → Share with OS-AID** и выбери **Trio**, чтобы передавать обычные показания глюкозы в совместимую установку Trio.

Запуск нового сенсора, NFC-пробуждение, работа после прежнего срока и аппаратная проверка семейства AiDex ещё требуют испытаний. Автоматические тесты проверяют программную логику; физическую работу сенсора они не подтверждают.
